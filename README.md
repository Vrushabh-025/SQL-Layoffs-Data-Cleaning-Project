# SQL-Layoffs-Data-Cleaning-Project

Project Overview

This project focuses on cleaning and preparing a layoffs dataset using SQL.
The analysis includes identifying duplicate records, standardizing inconsistent
data, handling missing values, and converting data into the correct format.

Data Cleaning Steps

- Removed duplicate records
- Standardized inconsistent text
- Cleaned company, industry, and country values
- Converted date values into DATE format
- Identified and handled NULL and blank values
- Removed unnecessary column

Project File
`SQL_PROJECT.sql` contains the complete SQL cleaning process.
